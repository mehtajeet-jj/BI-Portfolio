# BI Portfolio

Hi, I'm Jeet — an Economics Honours graduate from Acadia University, currently working as a Junior Analyst at Dalhousie University's Office of Institutional Planning and Effectiveness (OPIE). In that role, I use existing Power BI dashboards to support advanced data analytics for executive decision-making on institutional direction.

This repository is where I build and sharpen my own dashboard-building skills, developed through hands-on certification coursework in Power BI and IBM Cognos Analytics.
